# 小白做 SaaS 落地页使用指南

这份指南假设你完全不会写代码。你只需要会：打开文件夹、复制粘贴、改文字、按回车。

## 先记住三句话

1. 页面是“代码文件”做出来的。
2. 改完代码后，要执行一次“上线”命令，网址才会更新。
3. 你已经有一套做好的模板，不需要从零开始。

## 你只需要记住三个命令

```text
npm install   第一次打开项目时执行一次
npm run dev   在电脑上预览页面
npm run deploy   打包并发布到网上
```

## 第一步：打开项目

1. 找到项目文件夹：`D:\火山界面复刻`。
2. 在文件夹地址栏输入 `cmd`，按回车，会打开黑色窗口（终端）。
3. 输入 `npm install`，按回车，等它跑完（第一次需要几分钟）。

## 第二步：在电脑上预览

1. 在刚才的黑色窗口输入 `npm run dev`，按回车。
2. 打开浏览器，访问 `http://127.0.0.1:5173/`。
3. 你就能看到网站了。以后改完文件，刷新浏览器就能看到变化。

## 第三步：修改文字和内容

1. 下载并安装 VS Code（免费），用它打开 `D:\火山界面复刻` 文件夹。
2. 左侧文件列表里，`src/pages` 文件夹放的是各个页面。
3. 双击文件，找到引号里的中文文字，直接改成你自己的。

常用位置：

| 想改什么 | 去哪个文件 |
| --- | --- |
| 首页活动内容 | `src/App.tsx` |
| 大模型页面 | `src/pages/Models.tsx` |
| 产品页面 | `src/pages/Products.tsx` |
| 解决方案页面 | `src/pages/Solutions.tsx` |
| 定价页面 | `src/pages/Pricing.tsx` |
| 价格和套餐数据 | `src/data/pricing.ts` |
| 顶部导航文字 | `src/components/Header.tsx` |
| 页脚文字 | `src/components/Footer.tsx` |
| 整体颜色 | `tailwind.config.js` |

改完保存（Ctrl+S），然后刷新浏览器看效果。

## 第四步：新增一个页面（照抄模板）

1. 复制 `docs/templates/NewPage.tsx`，粘贴到 `src/pages/` 里，改成你想要的名字，比如 `About.tsx`。
2. 用 VS Code 打开这个文件，把标题、副标题、卖点改成你自己的。
3. 打开 `src/main.tsx`，照着文件里的写法加一行：

```tsx
const About = lazy(() => import("@/pages/About"))
```

再在路由里加一行：

```tsx
<Route path="/about" element={<About />} />
```

4. 打开 `src/components/Header.tsx`，在 `NAV_ITEMS` 里加一行：

```tsx
{ path: "/about", label: "关于我们" },
```

5. 保存，刷新浏览器，新页面就出现了。

## 第五步：发布上线

1. 在黑色窗口按 `Ctrl+C` 停止预览。
2. 输入 `npm run deploy`，按回车。
3. 等它跑完，打开 `https://volcano-replica.pages.dev/` 就能看到线上版本。

以后每次改完内容，都执行一次 `npm run deploy`，线上就会更新。

## 第六步：换成自己的域名

1. 登录 Cloudflare，打开 Pages 项目，添加自定义域名。
2. 到买域名的网站（比如阿里云），把域名 DNS 改成 Cloudflare 给的两个地址。
3. 等生效（一般几分钟到几小时），访问 `https://你的域名` 就可以了。

## 常见问题

**改完没变化？**

先保存文件，再刷新浏览器。如果还是没变，在终端按 `Ctrl+C`，重新运行 `npm run dev`。

**执行命令时报错？**

不要慌，把终端里的红色英文复制下来发给帮你做页面的人。

**改坏了怎么办？**

Cloudflare Pages 里有历史版本，可以一键回滚到之前的版本。也可以在电脑上复制一份项目文件夹做备份，改坏了就把备份放回去。

**想在原模板上做新项目？**

先把整个文件夹复制一份，在新副本里改，别在原项目上直接乱改。

## 最重要的一条

不要怕点错。所有操作都可以重来：本地可以重新复制，线上可以回滚。大胆改，改完保存、预览、上线，三步走。
